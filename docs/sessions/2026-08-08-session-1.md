Grammar shapes confirmed by dumping real parse trees rather than assuming:

- `#[contractimpl]` is a **preceding sibling** of `impl_item`, not a child, and
  attributes stack.
- `binary_expression` has fields `left` / `operator` / `right`;
  `compound_assignment_expr` (`+=`) is a separate node kind with the same
  fields.
- `let_declaration` has `pattern` / `type` / `value`; `type_cast_expression`
  has `value` / `type`.
- A method call is `call_expression → function: field_expression → field:
  field_identifier`, and the call expression starts at the head of the whole
  chain — which is why findings anchor to the field, not the call.

## Decisions

**The parser is not in the rule API.** `internal/syntax` owns tree-sitter and
exposes `Node`; `rule.Node` aliases it. A test asserts tree-sitter is named in
exactly one file. This started as a constraint and paid for itself: `Text()`
needs no source argument, so the `src []byte` parameter disappeared from every
helper, and an absent node became the zero `Node` with safe accessors instead of
a nil pointer.

**`Check` returns no error.** A rule inspecting an in-memory tree has nothing to
fail at. Giving it an error channel would invite misuse.

**The engine stamps severity, not the rule.** `Meta.Severity` is a default. The
engine holds override and disable maps keyed by rule ID. That is the seam
`.plumbline.toml` will populate, and no rule will change when it lands.

**Severities are unranked in `internal/rule`.** Ranking is policy about failing
a build, so it lives in the CLI (`--fail-on`) and in `internal/report` (GitHub
spells the lowest level `notice`).

**No visitor/dispatch layer.** With three rules it buys nothing and costs
legibility. If traversal cost becomes real, the engine can add shared dispatch
behind the same `Check` signature without touching a rule.

**A file that does not parse is skipped, not linted.** A rule reading a broken
tree reports nonsense. Skips are surfaced, not swallowed.

## Rule scoping

- `missing-auth` does **not** treat `extend_ttl` as a state mutation, because a
  TTL bump carries no authority. It follows calls into same-file helpers, since
  the idiomatic shape puts the check in `require_admin()`. `__constructor` is
  exempt — the deployer authorizes it by deploying.
- `panic-in-contract` matches `unwrap` and `expect` **exactly**, which excludes
  `unwrap_or` / `unwrap_or_else` / `unwrap_or_default` for free — those are the
  recommended way to read an absent entry. It does not yet follow calls into
  helpers; the fail fixture pins that boundary.
- `unchecked-arithmetic` is scoped to 128-bit and unresolvable operands. Width
  inference leans on Rust requiring both operands of an operator to share a
  type, so resolving one side resolves the expression. Unsuffixed literals carry
  no type information, which keeps constant expressions like `120 * 17280` out.

## Things that went wrong

- `.gitignore` had an unanchored `plumbline`, which matches the
  `cmd/plumbline/` **directory**. `git add` skips ignored paths silently, so a
  commit claiming to add the CLI contained only the report package and
  everything still built. Anchored to `/plumbline`, with a comment.
- The published golangci-lint install script failed checksum verification;
  installed through the Go module proxy instead.
